# CRM User Guide

## 1. Как войти в CRM
1. Открой ссылку на CRM в браузере.
2. Введи свой email и пароль.
3. Нажми кнопку `Войти`.
4. После входа ты увидишь главный экран с показателями и последними заявками.

## 2. Главный экран
1. В верхней панели находятся основные разделы: `Dashboard`, `Заявки`, `Клиенты`, `Задачи`, `Настройки`.
2. В центре главного экрана показаны ключевые цифры по бизнесу.
3. Ниже находится список последних заявок.
4. Через кнопку `Открыть` можно сразу перейти в нужную карточку.

## 3. Как создать новую заявку вручную
1. Нажми кнопку `Новая заявка` в верхней панели или `Добавить заявку` в разделе `Заявки`.
2. Заполни имя клиента, телефон, услугу и остальные поля.
3. При необходимости добавь комментарий и follow-up.
4. Нажми `Добавить заявку` — заявка сразу появится в CRM.

## 4. Как обработать входящую заявку с сайта
1. Клиент отправляет форму на сайте.
2. Заявка автоматически появляется в CRM в разделе `Заявки`.
3. Открой карточку и проверь данные клиента.
4. После этого можно сменить статус, поставить follow-up и добавить заметку.

## 5. Как изменить статус заявки
1. Открой нужную заявку.
2. В карточке заявки найди блок со статусами.
3. Нажми на нужный статус.
4. Система сразу сохранит изменение и добавит его в историю.

## 6. Как назначить заявку на мастера
1. Открой нужную заявку.
2. Убедись, что по ней заполнены основные данные.
3. Owner или manager назначает её в работу мастеру.
4. После этого мастер увидит её в своём рабочем интерфейсе.

## 7. Как добавить комментарий или заметку
1. Открой карточку заявки.
2. Найди блок внутренней заметки.
3. Напиши короткий комментарий по клиенту или следующему шагу.
4. Нажми `Добавить заметку`.

## 8. Как посмотреть историю клиента
1. Открой раздел `Клиенты`.
2. Выбери клиента в списке.
3. Переключай вкладки `История`, `Заявки`, `Заметки`.
4. Так ты увидишь, что уже происходило по этому клиенту.

## 9. Как работают напоминания
1. Для заявки можно поставить дату и время follow-up.
2. Когда наступает нужное время, система отправляет напоминание.
3. По новым заявкам и сводкам также приходят уведомления в Telegram.
4. Все действия остаются в истории клиента и заявки.

## 10. Как выйти из аккаунта
1. В правой верхней части экрана найди кнопку `Выйти`.
2. Нажми её один раз.
3. CRM завершит сессию и вернёт тебя на экран входа.
