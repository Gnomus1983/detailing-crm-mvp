# DEMO SALES WALKTHROUGH - 2026-06-03

## Goal

Show the product as a practical workflow system for a local detailing business, not as a generic CRM.

## Best Demo Story

Use this story:

- a new client request comes from Instagram / landing page
- the request appears instantly in CRM
- manager sees source, service, car, comment, and preferred slot
- manager sets follow-up
- automation sends Telegram alert / reminder
- technician later sees only the assigned work

## Suggested Lead To Show

Primary lead for the demo:
- `Victor Sandu`
- service: `Consultatie pentru coating ceramic`
- status: `Ofertat`
- source: `Instagram`
- believable premium intent

Secondary lead:
- `Public Demo Client`
- use this only to show public intake / incoming request behavior

## Recommended Demo Order

1. Open `Panou`
2. Show that this is a live operational screen:
   - solicitari noi
   - follow-up-uri
   - valoare / activitate
3. Open `Solicitari`
4. Open `Victor Sandu`
5. Explain the card:
   - service
   - source
   - preferred slot
   - follow-up
   - comment
6. Show timeline / note history
7. Mention that alerts and reminders already work through Supabase-native automations
8. Switch role view:
   - owner
   - manager
   - tehnician detailing
9. Show that the technician sees only assigned work

## Core Sales Message

This is not just a CRM table.

It is:
- request intake
- lead tracking
- follow-up control
- Telegram automation
- role-based workflow for a small service team

## What To Avoid During Demo

- do not show too many old duplicate demo leads
- do not start from `Settings`
- do not explain architecture first
- do not pitch it as a huge universal CRM

## Short Pitch

`Aceasta este o mini platforma operationala pentru detailing: preia cererile, le organizeaza, nu lasa follow-up-urile sa se piarda si arata fiecarui om doar ce trebuie sa vada.`
