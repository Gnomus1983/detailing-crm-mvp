# Roles And Access

## Owner

**Кто это в компании:** директор или владелец бизнеса.

**Что видит в интерфейсе:**
- все разделы CRM
- заявки
- клиентов
- задачи
- настройки

**Что может делать:**
- создавать и обрабатывать заявки
- менять статусы
- ставить follow-up
- добавлять заметки
- смотреть клиентскую историю
- управлять настройками
- назначать роли пользователям

**Что не может делать:**
- в текущем MVP у этой роли почти нет ограничений

**Как назначается роль:**
- роль записывается в профиле пользователя
- owner может назначить роль `owner`, `manager` или `detailer`

## Manager

**Кто это в компании:** администратор, менеджер по клиентам, оператор входящих заявок.

**Что видит в интерфейсе:**
- dashboard
- заявки
- клиентов
- задачи

**Что может делать:**
- создавать заявки
- обрабатывать входящие заявки
- менять статусы
- ставить follow-up
- добавлять заметки
- вести клиента до записи

**Что не может делать:**
- не управляет системными настройками owner-уровня
- не имеет полного административного доступа

**Как назначается роль:**
- owner назначает эту роль пользователю в системе

## Technician / Detailer

**Кто это в компании:** мастер, исполнитель работ, техник детейлинг-центра.

**Что видит в интерфейсе:**
- только назначенные ему заявки
- рабочую историю по этим заявкам
- свой операционный экран

**Что может делать:**
- открывать назначенные заявки
- смотреть данные клиента
- видеть историю действий по работе

**Что не может делать:**
- не создаёт новые заявки
- не управляет настройками
- не видит лишние заявки других сотрудников
- не получает полный менеджерский доступ

**Как назначается роль:**
- owner переводит пользователя в роль `detailer`
- затем owner или manager назначает ему заявки

## Как owner создаёт пользователя и назначает роль

1. Новый сотрудник получает аккаунт в CRM.
2. Owner открывает управление доступом.
3. Owner выбирает нужную роль: `owner`, `manager` или `detailer`.
4. После этого пользователь входит в CRM и видит свой набор разделов и действий.

## Как это работает в реальной компании

- **Owner** контролирует весь процесс и систему целиком.
- **Manager** ведёт клиентов, заявки и follow-up.
- **Technician / Detailer** видит только назначенную ему работу.
